# Bumerang-Duell VR

Privater VR-Prototyp (WebXR, Meta Quest 3) – 1 gegen 1, zwei Headsets im selben WLAN.
Inspiriert vom Couch-Spielprinzip „Bumerang werfen, fangen, One-Hit-KO“. Eigener Code, keine Original-Assets.

Spielen: https://stargamery-svg.github.io/boomerang-fu/ auf beiden Quests öffnen, gleichen Raum-Code wählen, „VR STARTEN“.
